# Code and data rights

This repository is a reconstruction and refactoring of an existing research project. Original collaborator and third-party rights remain with their respective holders. No blanket open-source license is asserted here; public visibility alone is not a license grant. A code license can be added after collaborator rights are confirmed.

Only independently generated synthetic input data are bundled. Original source reports, provider workbooks and original participant-level records are not redistributed. The reference tables describe local reconstruction runs, not a license to the underlying data. Input access and redistribution terms must be handled separately.
