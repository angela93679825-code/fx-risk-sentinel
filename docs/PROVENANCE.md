# Provenance and attribution

Original report: *FX Risk Sentinel: AI and Econometrics for Predictive Risk Analysis*, Yinquan Hou and Yixuan Wang, July 4, 2025. The project is collaborative; the provided materials do not establish individual module-level attribution.

This portfolio version organizes recovered formulas and control flow into reusable modules, supplies independent synthetic examples, and records the original-data execution audit. The original report and proprietary/provider source files are not republished. Refactoring and generated documentation are part of the subsequent reproducibility work.

Reference results were obtained during the reconstruction on October 25, 2026. Source code and data versions are identified in results/reference/provenance.json. Reference results are explicitly distinct from the synthetic demo.
