# Reproduction notes

The source was the user-supplied July 2025 report, its PDF appendices and the archived data. No runnable original `.py` or notebook was found in the supplied archive. PDF line breaks, smart quotes, truncated paths and column-name loss were repaired before refactoring.

## What the reference results mean

`full_rebuilt_metrics.csv` uses freshly generated technical indicators and the mapped country-level macro inputs. It does not use the richer archived selected-feature matrices. The reconstructed raw-feature experiment therefore differs from the supplied-feature experiment.

`target_comparison.json` compares the exact shifted rolling standard deviation against the four original target tables. The USDCNH prices came from the archive's `multi/USDCNH.all/USDCNH/USDCNH.FX.xlsx`; the remaining four prices came from `code/FX_cleaned/`.

`single_asset.csv` reproduces Appendix L and Table 10. It does not implement transaction costs, volatility sizing or the `risk_threshold` setting that were absent or unused in the supplied code. The unused source settings are not exposed as working features here.

`portfolio_metrics.json` retains the source's 365-day annualization, annual risk-free rate 0.025, 21-row train window, five-row test window and 0.001 turnover cost. The annualized return is the arithmetic mean of daily returns multiplied by 365, not CAGR. Risk constraints are keyed explicitly to currency names; the source filesystem iteration order was not a reliable asset order. Zero triggered gates in this reconstruction imply no demonstrated benefit from filtering.

## Changes made for a reusable repository

- Normalized schema and explicit input errors replace hard-coded desktop paths.
- CSV files replace generated workbooks; original numeric formulas are retained.
- Date parsing and input provenance are explicit.
- Optimizer failures and risk-gate status are counted instead of hidden.
- Empty features and missing predictions fail clearly rather than silently changing the model.
- Single-thread execution avoids the runtime-library instability observed during the first audit.
- Legacy filtering is named `legacy_select`; its look-ahead limitation is documented.

PCA and Black-Litterman discussions in the report are not represented here as completed executable modules because no corresponding full implementation was supplied.

## Next research steps

Fit selection only inside rolling training folds; add a purging gap; use consistent training-calibrated risk thresholds; apply only contemporaneously available predictions to allocation; model release dates, transaction costs and live execution assumptions. These are future method changes, not claims about this version.

In the reusable importer, repeated macro basenames are explicitly namespaced by country (for example CHN__GEPU_current and US__GEPU_current). This removes ambiguous duplicate columns rather than reproducing the PDF script's duplicate-name expansion. Feature order/selection and resulting scores can therefore differ from the earlier literal-source audit. The included full_rebuilt_metrics.csv is generated by the current modular code, not copied from that earlier audit.
